# Reproducibility Guide

## Protocol Identity

The six primary benchmarks use a fixed 80/10/10 scaffold-balanced split with
split seed 0. Model seeds are 0--4. Evaluation budgets are 0%, 5%, 10%, 20%,
40%, 60%, 80%, and 100%; 20% is the principal budget upper bound. Regression
tasks are evaluated by MAE and classification tasks by AUROC.

The two base experiment directories are produced as follows:

| Group | Tasks | 3D representation | Output directory |
| --- | --- | --- | --- |
| Classification | BACE, BBBP, HIV | USR ensemble statistics | `results/if_oof_usr_rdkit2d_combo_cls_5seed` |
| Regression | ESOL, FreeSolv, Lipophilicity | scalar 3D descriptors | `results/if_oof_scalar_rdkit2d_combo_reg_5seed` |

Both runs use RDKit 2D combination features, 10 ETKDG conformers, five-fold OOF
utility labels, and five model seeds. The exact parameters are recorded in
`configs/paper_protocol.yaml` and expanded into commands by
`scripts/reproduce_paper.sh`.

## Operational Policy and Fold-Separated Calibration

The operational policy selects the router objective, feature group, and gate
from OOF evidence, then applies the selected-set Utility-LCB permission rule.
Its budget is an upper bound, so the realized call rate may be lower than the
nominal budget or zero.

The fold-separated analysis excludes one OOF fold from router and gate
selection and uses that fold to estimate the permission criterion while
retaining the same held-out test protocol.

## Reference Results

Compact reported outputs are stored in `results/reference/` using the original
experiment directory names. These tables include:

- five-seed R9 and fold-separated calibration summaries;
- task-level and normalized budget-integrated gain;
- objective, input, fusion, noise, missing-modality, and label-efficiency
  analyses;
- QM9-MU/R2 stress-test summaries;
- same-protocol prediction comparisons, risk-coverage, a paired five-seed
  conformer-count control with identical 2D predictions, and acquisition cost.

Large feature matrices and molecule-level predictions are regenerated by the
pipeline and are intentionally not versioned.

## Verification

Verify the bundled reference tables:

```bash
python scripts/verify_reference_results.py
```

After downloading the datasets, verify their identities as well:

```bash
python scripts/verify_reference_results.py --data-dir data/raw
```

For a generated result directory, retain `run_metadata.json`; each experiment
records its arguments, software platform, and relevant protocol note there.
